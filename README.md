# Pune Square

Informational guide to Pune's residential real estate corridors.

## Local development

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Deploying

Push this repo to GitHub, then import it in Vercel (see chat for full walkthrough).
No environment variables are required for the current feature set — project
data is stored in the visitor's browser (localStorage) via `lib/projects.ts`.
